# 用户使用指南

欢迎使用密码学平台！这是一个集成了多种密码算法和协议的教学演示平台，采用现代化的 Fluent Design 界面。

## 快速开始

### 系统要求

- Windows 10/11 (64位)
- 无需安装 Python 或其他依赖

### 安装步骤

1. 下载最新版本（从 GitHub Releases 或打包文件）
2. 解压到任意目录
3. 双击 `密码学平台.exe` 启动程序

### 界面说明

程序启动后，您会看到：

- **首页** - 显示所有算法分类卡片
- **左侧导航栏** - 快速访问各个分类
- **设置** - 主题切换、关于信息

## 使用技巧

### 算法介绍

部分算法提供了详细的 HTML 介绍页面：

1. 点击算法卡片进入算法界面
2. 点击右上角的 "算法介绍" 按钮
3. 查看算法原理、历史、应用等

### 主题切换

1. 点击左下角的 "设置" 按钮
2. 选择主题：
   - 浅色主题
   - 深色主题
   - 跟随系统

### 输入格式

- **十六进制输入**: 使用空格分隔，如 `01 23 45 67`
- **文本输入**: 直接输入文本
- **密钥输入**: 根据算法要求输入指定长度

### 操作日志

每个算法界面都有操作日志区域，显示：

- 操作步骤
- 计算结果
- 错误提示

## 常见问题

### Q1: 程序启动慢

**原因**: 首次启动需要加载所有模块

**解决**:
- 首次启动需要 10-20 秒，属于正常现象
- 后续启动会更快

### Q2: 杀毒软件拦截

**原因**: 可能被误判为未知程序

**解决**:
- 添加到杀毒软件白名单
- 程序是安全的，可以放心使用

### Q3: 界面显示异常

**原因**: 分辨率或缩放设置问题

**解决**:
- 调整窗口大小
- 修改系统缩放比例
